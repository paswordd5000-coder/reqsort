# ReqSort

## 概要
ReqSortは、利用者が入力したシステムへの要望を、機能要件、非機能要件、確認事項に簡易分類するWebアプリである。要件定義の初期段階で、曖昧な表現を見つける練習を目的とする。

## 主な機能
- 一行単位の要望入力
- キーワードに基づく機能要件と非機能要件の分類
- 「使いやすい」「高速」など曖昧な表現への確認事項の提示

## Dockerでの実行
```bash
docker build -t reqsort .
docker run --rm -p 5000:5000 reqsort
```
ブラウザで `http://localhost:5000` を開く。

## 使い方
テキスト欄に要望を一行ずつ入力し、「要件を整理する」を押す。分類結果が三つの欄に表示される。

## 注意
本アプリは学習用の単純なルールベース分類であり、実際の要件定義を自動化するものではない。分類結果は必ず人間が確認する。
